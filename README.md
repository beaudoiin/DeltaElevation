# DeltaElevation
Model elevator system. Employs an arduino micro controller for logical control, aswell as an ESP32 HMI screen for Scada control. Made with 3D printing, features a 3 floor elevator shaft with model floors. Uses electronic componenets such as: DFMini player, Shift Registers, RTC, IIC leveler, SD reader, BT_2 motor driver and other various componenets
